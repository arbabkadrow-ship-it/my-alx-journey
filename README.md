# my-alx-journey
A personal archive of my ALX learning journey — notes, lessons, and projects from each course.

A personal, permanent record of my ALX learning journey — every course, every valuable lesson, written in my own words so it outlives the subscription.

## Why this exists

ALX access is time-limited, and only milestone files can be downloaded from the platform. The course content isn't mine to keep — but the journey and everything I've learned along the way is. This repo is where that lives.

## Rule of thumb

Every time I finish a module or a course, write in journey-log.md first — the big lesson, not the syllabus. Then, if the course has technical depth (like Cybersecurity), add the detailed notes/cheatsheets/projects in that course's own folder.
